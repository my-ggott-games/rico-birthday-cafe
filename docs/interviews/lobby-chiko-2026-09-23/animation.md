# 애니메이션 & 연출

> Source: Deep Interview, 2026-09-23

## Key Points
- 방향별 프레임 1장 → **이동 중 통통 튀기(bounce) + 좌우 기울기(sway)** 로 걷는 느낌 (Framer Motion)
- 정지 시: 숨쉬기(살짝 scale) idle
- **드래그 중:** 정면 이미지 + 살짝 커짐 + 몸이 들려 그림자와 떨어짐 → 드롭 시 "통" 착지
- **발밑 타원 그림자** 사용
- **원근감:** 놀이터 위쪽일수록 작게 (y 비율에 따른 scale)

## 방향 → 스프라이트 매핑 (이동 벡터 기준 8방향)
| 이동 방향 | 이미지 |
|---|---|
| ↓ (아래/화면 쪽) | 정면 |
| ↑ (위/화면 안쪽) | 뒷면 |
| → | 옆면(우) |
| ← | 옆면(좌, 반전) |
| ↘ | 대각선 앞(우) |
| ↙ | 대각선 앞(좌, 반전) |
| ↗ | 대각선 뒤(우) |
| ↖ | 대각선 뒤(좌, 반전) |

## Open Questions
- 겹침 시 z-order: y 기준 정렬을 명시적으로 고르진 않았으나, 원근감을 쓰면 y-sort가 자연스러움 → 기본값으로 y-sort 적용 제안
- 치코끼리 회피는 선택 안 함 → 겹침 허용 (클릭 시 앞의 치코가 우선)
- 원근 스케일 범위 (예: 0.8 ~ 1.0)
