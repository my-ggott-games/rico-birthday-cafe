# 남은 질문

> Source: Deep Interview, 2026-09-23

## 상호작용
- 클릭/드래그 판별 임계값 (제안: 이동 6px 이상이면 드래그)
- 드래그 중 다른 치코 위로 드롭 시 처리 (겹침 허용 가정)
- 모바일: 첫 탭 후 말풍선 자동 닫힘 시간 여부

## 연출
- 원근 스케일 범위 (제안: 0.8 ~ 1.0)
- z-order y-sort 적용 확정 여부
- 배회 이동 속도 (제안: 놀이터 폭 기준 초당 ~8%)

## 모션 줄이기
- 숨쉬기 idle 유지 vs 완전 정지 ("움직이지 않음"과 충돌 가능)
- 모서리 버튼 위치 — 모바일 `who am I?` 고정 버튼(좌하단)과 겹치지 않는 코너 선택 (제안: 우하단)

## 레이아웃
- 놀이터 최소 높이 (모바일 짧은 화면)
- 랜덤 초기 위치 시 치코가 너무 몰리는 경우 최소 간격 보정 여부

## 에셋
- 출력 해상도 (제안: 높이 320px, 7rem@2x 커버)
- 추후 게임별 코스튬 제작 시점

## 구현 시 적용한 기본값 (2026-09-23, 변경 가능)
- 드래그 판별: 6px 이상 이동 시 드래그
- 원근 스케일 0.8(위) ~ 1.0(아래), z-order는 y 기준
- 걷기 속도 70px/s (1~3초로 clamp), 한 번에 가로 최대 40% / 세로 최대 50% 이동
- 모션 줄이기 ON: 숨쉬기 idle도 끔 (완전 정지), 드래그 불가
- 모션 줄이기 버튼: 놀이터 **우상단** (하단은 전역 Mute/쪽지 고정 버튼과 겹쳐서 이동)
- 치코 이동 영역 하단을 고정 버튼 높이만큼 비움 (모바일 bottom-10, PC bottom-8)
