# 치코 이동 & 상호작용

> Source: Deep Interview, 2026-09-23

## Key Points
- 게임 4개 = 치코 4마리 (각 치코가 하나의 미니게임 진입 버튼)
- **자율 배회**가 기본 동작
- 사용자가 **드래그 앤 드롭**으로 치코 위치를 옮길 수 있음
- 드롭 후 **2초** 대기 → **드롭된 현재 위치에서** 자율 배회 재시작
- **클릭과 드래그를 반드시 구분**해야 함
  - 클릭(탭) → 해당 미니게임으로 진입
  - 드래그 → 이동만, 게임 진입 없음

## Details
- 프로젝트 DnD 라이브러리는 `@dnd-kit` (CLAUDE.md). 단, 자유 좌표 드래그 + 배회 애니메이션 조합이라 Framer Motion `drag` 또는 pointer 이벤트 직접 처리도 후보
- 클릭/드래그 판별 기준 후보: 이동 거리 임계값(예: 5~8px) + 누른 시간

## Open Questions
- 클릭/드래그 판별 임계값 (거리 / 시간)
- 드래그 중 치코 방향 스프라이트 처리 (드래그 방향 따라 회전? 특정 포즈?)
- 치코끼리 겹침 허용 여부
- 배회 속도, 정지 시간, 방향 선택 규칙

## 추가 확정 (Round 3)
- 드래그 중 연출: 정면 이미지 + 들림 (→ animation.md)
- 치코끼리 회피 로직 없음 (겹침 허용)

## 배회 파라미터 (Round 4)
- 성격: **느긋하게** — 짧게 걷기(1~3초) → 길게 쉬기(2~5초)
- **PC 호버 시 해당 치코 정지 + 정면 바라봄** (이름 표시와 동시)
- 모바일 첫 탭 시에도 배회 일시정지 (game-identification.md)

## 위치 영속성
- 드래그로 옮긴 위치 **저장 안 함** — 로비 진입마다 기본/랜덤 위치에서 시작

## 초기 위치 (Round 6)
- 로비 진입 시 **완전 랜덤** 위치 (겹침 가능)
