# 요약 — 로비 치코 게임 선택 버튼

> Source: Deep Interview, 2026-09-23

## 한 줄 요약
로비의 게임 타일 4개를 **슬로건 아래 놀이터에서 느긋하게 배회하는 치코 4마리**로 교체한다. 클릭하면 게임 진입, 드래그하면 이동, 드롭 2초 후 그 자리에서 배회 재개.

## 확정 사항
| 영역 | 결정 |
|---|---|
| 개체 | 게임당 치코 1마리 (코디 / 퍼즐 / 아스파라거스 / 점프(용사 리코)), 모두 동일 스프라이트 |
| 이동 | 자율 배회 (걷기 1~3초 ↔ 쉬기 2~5초), 초기 위치 완전 랜덤, 치코끼리 회피 없음 |
| 드래그 | 자유 드래그, 클릭과 구분(거리/시간 임계값), 드롭 후 2초 뒤 현재 위치에서 배회 재시작, 위치 저장 안 함 |
| 드래그 연출 | 정면 이미지 + 들림(scale↑, 그림자 분리) → 착지 |
| 걷기 연출 | 방향 이미지 + bounce/sway, 정지 시 숨쉬기 |
| 방향 | 이동 벡터 기준 8방향, 좌측 3방향은 우측 좌우반전 파일 |
| 원근 | 위쪽일수록 작게, 발밑 타원 그림자 (z-order는 y-sort 제안) |
| 범위 | 슬로건 아래 `flex-1` 영역, 0~1 비율 좌표, 드롭 clamp |
| 크기 | 모바일 5rem / PC 7rem (원근 1.0 기준) |
| 이름 표시 | PC: 호버 시 이름 + 정지 + 정면. 터치: 첫 탭 이름 + 정지, 같은 치코 재탭 시 진입 |
| 판정 | 레이아웃 `width < 768`, 입력 `(pointer: coarse)` |
| 부가 | 비밀 쪽지 버튼 치코에 부착, 키보드 포커스/Enter 진입/aria-label, 퍼즐 언락 색상 힌트 제거 |
| 모션 줄이기 | 놀이터 모서리 작은 버튼, OS 기본값 + localStorage, ON 시 전원 정면·정지·균등 가로 한 줄(모바일 2x2)·드래그 불가 |
| 에셋 | `frontend/public/pages/lobby/chiko/*.webp` 8장, 투명·트림·동일 캔버스·발 끝 정렬, 게임→스프라이트 매핑 테이블 |

## 영향 받는 코드
