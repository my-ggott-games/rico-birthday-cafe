# 게임 구분 (어떤 치코가 어떤 게임인지)

> Source: Deep Interview, 2026-09-23

## Key Points
- 평소에는 치코만 보임
- **호버(PC) / 탭(모바일)** 시 게임 이름 표시


## 모바일 탭 규칙 (확정)
- 첫 탭: 이름 말풍선 표시 + 해당 치코 배회 일시정지
- 같은 치코 두 번째 탭: 게임 진입
- 다른 곳(빈 영역/다른 치코) 탭: 말풍선 닫힘 (다른 치코면 그 치코 말풍선으로 전환)
- PC: 호버 시 이름 표시, 클릭 즉시 진입

## Open Questions
- 현재 hotspot의 **비밀 쪽지 버튼**(관리자/이스터에그 노트)은 치코에 어떻게 붙일지
- 퍼즐 박물관 언락 시 퍼즐 타일 색 변경 로직 → 치코 버전 대응 필요 여부
